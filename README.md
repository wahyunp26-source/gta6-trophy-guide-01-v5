A complete trophy guide for Grand Theft Auto VI on PlayStation 5 — all 55 trophies, every step cited from sources read 20 Nov 2026, every disagreement between guides shown with both versions and our call.

## What is inside

- **Tracker** — tick trophies off, progress saved in your browser, export/import, filters (grade, type, Missable, Disputed, Watch, PSN-hidden, Not earned) and a spoiler setting that hides hidden trophies until earned.
- **Roadmap** — 5 stages from Chapter 1 to the platinum.
- **Missables** — the point-of-no-return table and the 5-save plan. Only one trophy can be missed.
- **Sources** — 14 pages across 8 sites, with per-source stats and the three big guide disagreements.

## Audit (computed from the data at runtime)

- 55/55 guides cite sources
- 347 steps cited, 347 backed by 2+ sources (100%)
- 29 disputes shown both ways (26 on trophies + 3 guide-level)
- 8 watch, 5 unconfirmed, 1 possible missable

## Run it

Serve `app/` with any static server and open `app/index.html`, or run `node serve.ts` and open http://localhost:8080.
